# Aesthetics

People ask for aesthetics by name: "make it vaporwave", "something Art Deco", "like a Bloomberg terminal". This file maps each name to the direction that carries it and gives the recipe for the change. A direction is a way of building screens (layout moves, signature details, component construction). Most named aesthetics are a palette, a material and one or two ornaments, so they ride on the direction whose structure already fits instead of becoming directions of their own.

- **variant**: the direction's layout moves and signature details fit as they are. Only the surface changes: colors, fonts, materials, ornaments. Apply the recipe below and the matching entry under that direction's `## Variants` section, `### Named aesthetics`.
- **partial**: the direction captures the look, but the aesthetic has structure of its own that no direction represents yet. The recipe says what's missing. Tell the user, build what the direction can carry, and don't fake the missing structure with decoration.

Some rows are aesthetics that are themselves tells of default AI UI (glassmorphism, neumorphism, claymorphism, aurora gradients, bento grid, neo-brutalism, corporate Memphis). They're listed because people ask for them. Each of those recipes says how to use the aesthetic on purpose and names the trap from `ANTI-SLOP.md`.

Recipes have not been built as specimens. Screenshot the result and run the self-check in `ANTI-SLOP.md` and the direction's Don'ts.
